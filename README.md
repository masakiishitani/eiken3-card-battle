# 英単語カードバトル

英単語を楽しく学べるカードバトルゲームです。クイズに答えながらカードを使って戦い、自動的に学習記録を蓄積して英語力を向上させましょう!

## 🚀 デプロイ済みゲーム

以下のURLからゲームをプレイできます!
**[https://eiken3-card-battle.vercel.app/](https://eiken3-card-battle.vercel.app/)**

## ✨ 主な機能

### 🎮 ゲーム機能
- **豊富な英単語データベース**: 665語の英単語を収録
  - 英検4級レベル: 300語（基礎レベル）
  - 英検3級レベル: 365語（標準レベル）
- **レベル選択**: 学習レベルに応じて4級・3級・混合モードを選択可能
- **クイズ形式学習**: 4択問題で英単語の意味を学習
- **AI対戦**: 一人でも楽しめる本格的なカードバトル
- **ターン制戦略ゲーム**: マナシステムによる戦略性

### 📊 学習記録システム
- **自動学習記録**: クイズの正解/不正解を自動的に記録
- **学習進捗可視化**: 習得済み・学習中・未学習の単語数を表示
- **正答率計算**: 単語別・全体の正答率を自動計算
- **習得レベル判定**: 正答率80%以上かつ3回以上で「習得済み」に自動昇格
- **復習システム**: 間違えた単語を重点的に復習可能

#### UI/UX機能
- **遊び方説明**: 6ステップの詳細チュートリアル
- **レスポンシブデザイン**: スマートフォン・タブレット・PCに完全対応
- **モバイル最適化**: 手札カードの自動折り返し表示で快適なプレイ
- **美しいアニメーション**: Framer Motionによるスムーズな演出
- **直感的な操作**: 初心者でも迷わない分かりやすいUI
- **タッチ操作対応**: スマートフォンでの快適なタップ操作

## 🎯 ゲームの目的

相手のHPを0にして勝利を目指しながら、英単語の意味を覚えていきましょう。正解すればするほど有利になる仕組みで、自然と学習効果が高まります。

## 📖 遊び方

### 🎮 基本ルール

1. **レベル選択**: 英検4級・3級・混合モードから選択
2. **プレイヤーとAIが交互にターンを行います**
3. **各プレイヤーのHP: 50、開始マナ: 10**
4. **手札から5枚のカードでスタート**

### 🔄 ターンの流れ

#### 1. ドローフェーズ
- 自動的にカードを1枚引きます

#### 2. メインフェーズ
- **カードをプレイ**できます
- カードをプレイするには:
  1. 手札のカードの「Play」ボタンをクリック
  2. 英単語クイズが表示されます（4択問題）
  3. 正しい意味を選択
  4. **正解**: カードがフィールドに出て、マナを消費、学習記録に記録
  5. **不正解**: カードは消滅し、マナは消費されず、学習記録に記録

#### 3. バトルフェーズ
- フィールドのカードで**攻撃**できます
- カードをクリックして相手を攻撃
- **攻撃成功時**: 与えたダメージ分のマナを獲得
- **同じカードは1ターンに1度のみ攻撃可能**

#### 4. ターン終了
- 「ターン終了」ボタンでターンを終了
- マナが1回復します

### 🃏 カードの見方

各カードには以下の情報があります:

- **英単語**: カードの名前
- **コスト**: プレイに必要なマナ（右上の黄色い数字）
- **攻撃力**: 与えるダメージ（左下の赤い剣アイコン）
- **防御力**: 受けるダメージを軽減（右下の青い盾アイコン）
- **品詞**: 動詞（赤）、名詞（青）、形容詞（緑）、副詞（紫）

### 🏆 勝利条件

相手のHPを0にすれば勝利です!

## 📊 学習記録機能の使い方

### 📈 学習進捗の確認
1. ゲーム画面右上の「学習記録」ボタンをクリック
2. 以下の情報を確認できます:
   - **習得済み単語数**: 正答率80%以上かつ3回以上挑戦した単語
   - **学習中単語数**: 1回以上挑戦したが習得に至らない単語
   - **未学習単語数**: まだ出会っていない単語
   - **全体正答率**: 全体の学習成績
   - **完了率**: 習得済み単語の割合

### 📝 単語別詳細情報
- 各単語の挑戦回数、正答数、正答率
- 初回遭遇日時、最終学習日時
- 現在の習得レベル（未学習・学習中・習得済み）

## 🎓 学習効果を高めるコツ

1. **継続的なプレイ**: 毎日少しずつプレイして単語に慣れ親しみましょう
2. **レベル別学習**: 基礎レベルから始めて基礎を固め、慣れたら標準レベルにステップアップ
3. **学習記録の活用**: 定期的に学習記録を確認し、苦手な単語を重点的に復習
4. **間違えた単語の復習**: 不正解だった単語は特に注意して覚えましょう
5. **品詞の意識**: カードの色分けで品詞も一緒に覚えられます
6. **戦略的思考**: どのカードをいつ使うか考えることで、単語への理解が深まります

## 🛠️ 技術仕様

### フロントエンド
- **フレームワーク**: React 18 + Vite 6
- **スタイリング**: Tailwind CSS + shadcn/ui
- **アニメーション**: Framer Motion
- **アイコン**: Lucide React
- **状態管理**: React Context + useReducer

### データ管理
- **単語データ**: 665語の英単語データベース
- **学習記録**: localStorage（ブラウザ内永続化）
- **データ構造**: JSON形式での効率的な管理

### デプロイメント
- **ホスティング**: Vercel
- **CI/CD**: GitHub連携による自動デプロイ
- **パフォーマンス**: 最適化されたビルド設定

## 🚀 開発・実行方法

### 必要な環境
- Node.js 18以上
- npm または yarn

### セットアップ
```bash
# リポジトリをクローン
git clone https://github.com/masakiishitani/eiken3-card-battle.git

# ディレクトリに移動
cd eiken3-card-battle

# 依存関係をインストール
npm install

# 開発サーバーを起動
npm run dev

# ビルド（本番用）
npm run build

# プレビュー
npm run preview
```

### 開発用コマンド
```bash
# 型チェック
npm run type-check

# リント
npm run lint

# フォーマット
npm run format
```
