# 英検3級カードバトル - 英単語学習ゲーム

英検3級レベルの英単語を楽しく学べるカードバトルゲームです。クイズに答えながらカードを使って戦い、英語力を向上させましょう！

## 🎮 ゲームの特徴

- **英検3級レベルの英単語**を使用したカードバトル
- **クイズ形式**で英単語の意味を学習
- **AI対戦**で一人でも楽しめる
- **約15ターン**で完了する適度なゲーム時間
- **レスポンシブデザイン**でスマートフォンでもプレイ可能

## 🎯 ゲームの目的

相手のHPを0にして勝利を目指しながら、英単語の意味を覚えていきましょう。正解すればするほど有利になる仕組みで、自然と学習効果が高まります。

## 📖 遊び方

### 基本ルール

1. **プレイヤーとAIが交互にターンを行います**
2. **各プレイヤーのHP: 50、開始マナ: 10**
3. **手札から5枚のカードでスタート**

### ターンの流れ

#### 1. ドローフェーズ
- 自動的にカードを1枚引きます

#### 2. メインフェーズ
- **カードをプレイ**できます
- カードをプレイするには：
  1. 手札のカードの「Play」ボタンをクリック
  2. 英単語クイズが表示されます
  3. 正しい意味を4択から選択
  4. **正解**: カードがフィールドに出て、マナを消費
  5. **不正解**: カードは消滅し、マナは消費されません

#### 3. バトルフェーズ
- フィールドのカードで**攻撃**できます
- カードをクリックして相手を攻撃
- **攻撃成功時**: 与えたダメージ分のマナを獲得
- **同じカードで何度でも攻撃可能**

#### 4. ターン終了
- 「ターン終了」ボタンでターンを終了
- マナが1回復します

### カードの見方

各カードには以下の情報があります：

- **英単語**: カードの名前
- **コスト**: プレイに必要なマナ（右上の黄色い数字）
- **攻撃力**: 与えるダメージ（左下の赤い剣アイコン）
- **防御力**: 受けるダメージを軽減（右下の青い盾アイコン）
- **品詞**: 動詞、名詞、形容詞、副詞（左上のアイコン）

### 勝利条件

相手のHPを0にすれば勝利です！

## 🎓 学習効果を高めるコツ

1. **間違えた単語を覚える**: 不正解だった単語は特に注意して覚えましょう
2. **品詞を意識する**: カードの色分けで品詞を覚えられます
3. **繰り返しプレイ**: 何度もプレイして単語に慣れ親しみましょう
4. **戦略を考える**: どのカードをいつ使うか考えることで、単語への理解が深まります

## 🛠️ 技術仕様

- **フレームワーク**: React + Vite
- **スタイリング**: Tailwind CSS + shadcn/ui
- **アニメーション**: Framer Motion
- **アイコン**: Lucide React
- **デプロイ**: Vercel

## 🚀 開発・実行方法

### 必要な環境
- Node.js 18以上
- npm または yarn

### セットアップ
```bash
# リポジトリをクローン
git clone https://github.com/masakiishitani/eiken3-card-battle.git

# ディレクトリに移動
cd eiken3-card-battle

# 依存関係をインストール
npm install

# 開発サーバーを起動
npm run dev

# ビルド（本番用）
npm run build
```
